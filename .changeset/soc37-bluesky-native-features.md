Bluesky: native features across publishing, reads, chat, drafts and video upload.

- Add Bluesky multipart video upload. `native.uploadVideoMultipart` sends `app.bsky.video.startUpload`, each `uploadPart` in order, and `finishUpload`, and `startVideoUpload`, `uploadVideoPart`, `finishVideoUpload`, `getVideoUploadStatus`, and `abortVideoUpload` expose each step for resuming. `media.upload` now uses the multipart upload for videos over 50,000,000 bytes.
- Bluesky adds compare-and-swap profile editing, post pinning, live status, account preferences, `swapRecord` on `updateProfile`, app-password `createBlueskySession` and `refreshBlueskySession` helpers, and Jetstream subscription and event-decoding helpers. `updateProfile` now rejects a record without `$type: "app.bsky.actor.profile"`; pass the full stored record, which already carries it.
- Bluesky adds sign-out (`deleteBlueskySession`, `revokeBlueskyOAuthSession`), app password management, handle changes, account deactivation, email and password flows, account creation and PDS migration helpers, and contact import.
- Bluesky native chat helpers now export and delete chat data, manage chat notification preferences, read unread counts, lock groups, page members, and manage group join links and join requests.
- Bluesky chat gains facets and shared posts on `sendMessage`, batch sends, starting a direct chat with `getConvoForMembers`, message requests, reactions, read state, mute, leave and delete-for-self helpers, the `getLog` event log, conversation filters, and beta group chat create, rename and membership calls.
- Bluesky native helpers now manage notification, chat and content-visibility declarations, profile links, reference list opt-outs, feed generator and labeler records, and build feed generator responses.
- Bluesky native reads add structured post search v2, grouped notifications, thread v2, trends and discovery suggestions, identity resolution, describeRepo, age assurance, starter pack membership, feed interactions, and enhanced link cards through `linkAssociatedRefs`.
- Bluesky publishing now supports hashtag facets, `tags`, self-labels, link cards, image galleries, video captions and presentation, quotes with media, reply controls and quote blocking (written atomically with `applyWrites`), plus native `uploadBlob`, `applyWrites`, threadgate and postgate editing, and server-side drafts.
- Bluesky adds native batch post and profile reads, thread depth controls, list, quote and repost feeds, feed discovery, suggestions, relationships, verification state, thread mutes, list memberships, starter packs, un-repost, bookmarks, labelers and labels, notification filters, unread counts, notification preferences and activity subscriptions, and reports bookmark counts as a metric.
- Bluesky likes, reposts and follows accept a `via` record, profiles set `joinedViaStarterPack`, follower reads take `sort`, mutes take `onlyReposts`/`onlyQuoteposts`, reports take `modTool`, and `createBlueskySession` takes `allowTakendown`.
- Bluesky `muteThread`, `unmuteThread`, `createBookmark`, `deleteBookmark` and `putPreferences` now accept the documented empty success response, and `posts.list` keeps gallery images.
- Bluesky drafts keep device-local images, galleries and video, `blueskyLabelStreamUrl` and `parseBlueskyLabelFrame` read a labeler's label stream, and `blueskyFeedGeneratorMethod` routes feed generator requests.
- Bluesky record writes that succeed without a readable URI and CID (`createProfileLink`, list opt-outs, and singleton declarations) now fail with `ambiguous_outcome` and `reconcile-first`. Declaration and gate reads treat only XRPC `RecordNotFound` (or HTTP 404) as a missing record; other rejections such as `InvalidRequest` are errors. `native.mute` accepts `onlyReposts` and `onlyQuoteposts` together. Draft media paths and captions are measured in UTF-8 bytes.
