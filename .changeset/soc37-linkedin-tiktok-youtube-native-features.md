LinkedIn, TikTok and YouTube: native features.

- LinkedIn native batch reads for social metadata, social actions, comments, reactions and media status, a single reaction lookup, member mention lookup by profile URL, and `interfaceLocales` post targeting.
- LinkedIn native operations add typed post reads with viewContext and poll results, batch get, reaction listing and deletion, social metadata, comment closing, top-level comments with mentions and images, comment editing and nested-reply reads; `posts.get` and `posts.list` now also return `publishedAt`, `isReshareDisabledByAuthor`, `content` and `reshareContext`.
- LinkedIn Events API natives: create, get, update and list events, upload event background images, and post events with `content.reference`.
- LinkedIn adds organization lookup, showcase discovery, role listing for any organization role, per-post and showcase page statistics, and member post, video and follower analytics; member `getAccountMetrics` now returns the follower count (needs `r_member_profileAnalytics`) instead of failing.
- LinkedIn token introspection (`introspectLinkedInOAuthToken`), Profile API reads (`getProfile`, `getPeople`), Organization Authorizations checks, and organization video analytics.
- LinkedIn publishing adds connections visibility, reshare control, mention and hashtag annotations, organic targeting, article thumbnails, poll limits, reshare commentary and typed post edits; native `react` now takes the documented reaction types and rejects deprecated `MAYBE`.
- LinkedIn video uploads now send a custom thumbnail from `media.thumbnail`, and native `uploadVideo` adds SRT captions and `templateName`/`linkbackContext` attribution; LinkedIn webhooks decode likes, reshares, mentions, comment edits and deletions to new event types (`reaction.received`, `post.reshared`, `mention.received`, `comment.updated`, `comment.removed`); native helpers manage event subscriptions and filter notification pulls by action, source post and time range.
- TikTok QR login accepts the documented `aweme://` scan URL; LinkedIn profile projections always request `id` so projections such as `(geoLocation(...))` decode; YouTube live chat streams report 403 `rateLimitExceeded` as `rate_limited`.
- `tiktokOAuth` accepts `disableAutoAuth: true` to always show TikTok's authorization page, the new `revokeTikTokOAuthToken` revokes a creator's access token through `/v2/oauth/revoke/`, and the docs now give TikTok's current 2-hour access and 180-day refresh token lifetimes.
- TikTok: `native.downloadDataRequest` keeps caller cancellation and the remaining budget in force while it reads a JSON error response, so a stalled error body can no longer hang after abort.
- TikTok: add Login Kit for Desktop PKCE (`tiktokLoginKit: "desktop"`), QR code login helpers, `refreshExpiresAt` from `refresh_expires_in`, `native.cancelPublish` for slow URL downloads, and Embed Player URL, command and event helpers.
- The TikTok adapter now supports `graph.getProfile` for the authorized creator, returning the avatar, display name and `union_id`, plus username, bio, profile link and verification when constructed with `userInfoProfile: true`, and adds `native.userInfo` with the exported `tiktokUserInfoFields` list.
- TikTok direct publishing adds `videoCoverTimestampMs` for video Direct Posts, accepts `autoAddMusic` on photo Direct Posts, returns the creator's two-hour `avatarUrl` from creator info, rejects photos over 20 MB when `byteSize` is known, sends only title and description for photo inbox drafts, and reports every post ID in `postIds` when one publish ID produced several posts.
- TikTok's `post.publish.no_longer_publicaly_available` webhook now decodes to `post.removed` instead of `publication.updated`, and the TikTok native module adds Data Portability requests (`addDataRequest`, `checkDataRequest`, `cancelDataRequest`, `downloadDataRequest`). Migration: handlers that read this event as `publication.updated` should also handle `post.removed`.
- YouTube native access adds Analytics groups and group items, and the Reporting API's report types, jobs, reports and bounded report downloads.
- YouTube native access adds channel banner upload (applied through updateProfile's bannerExternalUrl), watermarks, playlist images, and approval-gated channel members and membership levels.
- YouTube: `native.analyticsGroupItems` insert now returns `{ alreadyInGroup: true }` when Google answers `204 No Content` for an item already in the group, instead of throwing.
- YouTube adds `native.liveChatStream`, which reads live chat with `liveChatMessages.streamList` over HTTP (`GET /youtube/v3/liveChat/messages/stream`) and yields each page as it arrives.
- YouTube native liveBroadcasts adds update, delete, bind and ad cuepoints, and new liveStreams and superChatEvents methods complete the live streaming flow.
- YouTube adds live broadcast list filters, live chat `hl`, `profileImageSize` and poll closing, the remaining `search.list` filters (including `forMine` and `forDeveloper`), caption download `format` and `tlang`, embed `maxWidth`/`maxHeight`, comment lookup by ID, other channels' sections, `videoTrainability`, `abuseReports`, Google token revocation (`revokeGoogleOAuthToken`), and `include_granted_scopes`/`login_hint` on the authorize URL.
- YouTube native access adds videos (by ID, mostPopular, myRating), batchGetStats, channels by handle, videoCategories, i18n, reportAbuse, top-level comments, comment replies and more search, subscription and moderation filters, and comment lists surface imageUrl.
- YouTube uploads accept tags, defaultLanguage, localizations, license, embeddable, publicStatsViewable, containsSyntheticMedia, recordingDate and notifySubscribers, and `updateVideo` writes recordingDetails and localizations.
- LinkedIn DELETE requests, such as `native.deleteReaction` and `native.unsubscribeOrganizationNotifications`, now report a lost response, timeout or 5xx after dispatch as `ambiguous_outcome` with `reconcile-first` instead of a definitive failure.
- YouTube `native.liveChatStream` bounds an HTTP error body by the operation budget and `stallTimeoutMs`, so a stalled error response ends with its HTTP rejection instead of hanging.
- TikTok `native.addDataRequest` reports an accepted response with a missing, malformed or unsafe `request_id` as `ambiguous_outcome` with `reconcile-first`, since TikTok may already have created the export.
- YouTube native writes, including Analytics groups and group items, Reporting jobs, live, playlist, comment and channel writes and binary uploads, report an unusable success response as `ambiguous_outcome` with `reconcile-first` instead of a raw decode error.
